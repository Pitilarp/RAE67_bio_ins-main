WEEK 05 · RUNNABLE COURSE EXPERIMENT

Hormone เปลี่ยนคำสั่ง แล้ว CPG และการเคลื่อนที่เปลี่ยนอย่างไร?

เปรียบเทียบ B0 fixed, B1 direct, B2 hormone และ B3 binding ablation ด้วย stimulus เดียวกัน กราฟและตารางสร้างจาก CSV ของ run นี้ เปิดดู offline ได้

Proposed course model — stimulus กำหนดล่วงหน้า; contact มาจาก decoder; body เป็น kinematic stance-anchor model ไม่มี terrain, contact force หรือ body dynamics ผลนี้ยังไม่ยืนยัน ALCS, gait switching, Stability/Harmony ของ paper หรือความปลอดภัยหุ่นยนต์จริง

Receptor ที่ใช้สร้าง command

R_used ณ command_time = t_k; direct B1 อ่าน S_k ทันที ส่วน B2/B3 อ่าน hormone state ณ t_k

คำสั่ง φ ที่ส่งเข้า CPG

หน่วย rad; φ เป็น parameter ของ recurrence ไม่ใช่ frequency ที่วัดได้

การเคลื่อนที่ใน kinematic model

body_x ณ state_time; distance เป็นค่าของตัวจำลองรายวิชา ไม่ใช่ composite Displacement ของ paper

CPG output o₁

วัด frequency จาก rising crossings แยก pre/on/off; φ และ stride อาจเปลี่ยนทั้ง amplitude และ timing

Stride half command

ระยะครึ่ง stride ที่ใช้ใน decoder หน่วย m; phi-only คงค่านี้ที่ .055 m

Stimulus ที่กำหนดล่วงหน้า

ทุก condition ใช้ S เดียวกัน; fault เป็นช่องว่างที่ input15.00 s; ยังไม่มี independent feedback จาก body/terrain

ตรวจหนึ่ง interval และ state หลัง update

ภาพเป็น diagram ของ tripod decoder แสดงสีตาม contact ที่ decoder กำหนด ไม่ใช่แรงสัมผัส/รูปทรง MORF; fault reset H/R ก่อนใช้ command ของ interval นั้น

Metrics ของ run

TV รวมการเปลี่ยนจาก initial baseline เข้าสู่ command_0 และไม่เติม command หลังจบ trial; N/A เป็น null/ช่องว่างในไฟล์ ไม่ใช่ศูนย์

แยกผลตามช่วงเวลา

Frequency = 1 / mean period ระหว่าง rising crossings ใน [start,end); ประมาณเวลา crossing ด้วย linear interpolation ระหว่างสอง simulated states ต้องมี ≥2 crossings ใน segment ทั้ง on/off อาจยังมี transient จึงไม่เรียกว่า steady-state frequency

อ่านผลและตรวจ provenance

ผลทำซ้ำแบบ deterministic ไม่ใช่ independent trials และ bounds เดียวกันไม่ได้ทำให้ amplitude เท่ากัน การปรับ φ กับ stride พร้อมกันยังแยกสาเหตุไม่ได้ ให้ใช้ --mapping phi-only และ --mapping stride-only เป็นการทดลองต่อ

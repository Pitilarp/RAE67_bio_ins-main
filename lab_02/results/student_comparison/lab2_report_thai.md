# รายงาน Lab 02: Robust Reactive Lamp

## 1. วัตถุประสงค์
การทดลองนี้ศึกษาวิธีการควบคุมที่แตกต่างกันต่อการตอบสนองต่อเส้นทางระยะทางเดียวกันภายใต้สภาวะรบกวนจากเซ็นเซอร์และความล่าช้า โดยเปรียบเทียบพฤติกรรมของ controller ทั้งสี่แบบ C0–C3 ตามความเร็วในการตอบสนอง ความเสถียร และความทนทานต่อสัญญาณรบกวน

## 2. การตั้งค่าการทดลอง
การทดลองใช้ trajectory เดียวกันสำหรับทุก controller โดยกำหนดระดับ noise เท่ากับ 0.01 เมตร และ delay เท่ากับ 0 ms พร้อมทำซ้ำ 5 ครั้งต่อแต่ละ condition การประเมินผลใช้ตัวชี้วัดต่าง ๆ เช่น latency, recovery time, false-trigger rate, จำนวนการสลับ state และความเรียบของ command

## 3. การคาดเดาก่อนทำการทดลอง
ก่อนเริ่มทดลอง คาดว่าผลลัพธ์จะเป็นดังนี้:

1. C1 จะตอบสนองเร็วที่สุด เพราะใช้ single threshold กับ raw distance โดยตรง
2. C1 จะมี false trigger และ extra switching มากกว่าเพราะ noise สามารถทำให้ค่าของระยะทางข้าม threshold ซ้ำ ๆ ได้
3. C2 จะตอบสนองช้ากว่าเพราะ filter จะทำให้สัญญาณเรียบขึ้น และ hysteresis จะป้องกันการสลับสถานะอย่างรวดเร็ว
4. C2 จะมี false trigger น้อยกว่า และมีความเสถียรมากกว่า C1
5. C3 จะให้ command ที่เรียบและต่อเนื่อง แต่อาจถึงจุด saturated เมื่อ error มีค่า large

## 4. ผลลัพธ์
ผลรวมจากการทดลองเปรียบเทียบ controller ของนักศึกษาแสดงดังตารางต่อไปนี้

| Condition | Enter latency (s) | Exit latency (s) | Recovery time (s) | False triggers / min | Extra switches | Mean abs command change |
|---|---:|---:|---:|---:|---:|---:|
| C0 | 0.0029 | 2.8571 | 2.8571 | 2.9970 | 0.0 | 0.0012 |
| C1 | 0.0189 | 0.0291 | 0.1806 | 8.3916 | 12.4 | 0.0086 |
| C2 | 0.4069 | 0.4531 | 0.4543 | 0.0 | 0.0 | 0.0012 |
| C3 | 0.0429 | 0.0891 | 0.1091 | 1.7982 | 1.6 | 0.0046 |

## 5. การอภิปรายผล
### C1: ตอบเร็วแต่มีสัญญาณรบกวนมาก
C1 มี latency ในการเข้าระดับและออกจากระดับต่ำที่สุด ซึ่งแสดงให้เห็นว่าการใช้ single threshold กับ raw distance ทำให้การตอบสนองต่อเหตุการณ์ที่ระยะทางข้าม threshold เป็นไปอย่างรวดเร็ว อย่างไรก็ตาม false-trigger rate มีค่า 8.39 ต่อนาที และ extra-switches เท่ากับ 12.4 ซึ่งบ่งชี้ว่า noise ทำให้ state เปลี่ยนบ่อยมาก การสลับสถานะนี้เป็นข้อเสียหลักของ C1 เพราะไม่มีการกรองสัญญาณและไม่มี hysteresis

### C2: มีความเสถียรและทนทานมากกว่า
C2 มี latency ที่สูงกว่าความเร็วของ C1 โดยมี enter latency ประมาณ 0.407 วินาที และ exit latency ประมาณ 0.453 วินาที แม้จะช้ากว่า แต่ค่า false-trigger rate เป็น 0.0 และ extra-switches เป็น 0.0 ซึ่งแสดงว่าความเสถียรดีมาก การใช้ low-pass filter ร่วมกับ hysteresis ช่วยป้องกันการสลับสถานะจากการแกว่งเล็ก ๆ รอบ threshold ได้อย่างมีประสิทธิภาพ ดังนั้น C2 จึงแลกความเร็วเพื่อแลกกับความเสถียรและความทนทานต่อสัญญาณรบกวน

### C3: ควบคุมแบบ proportional ที่เรียบและต่อเนื่อง
C3 ให้ latency ประมาณ 0.043 วินาที สำหรับ enter และ 0.089 วินาที สำหรับ exit โดยมี false-trigger rate 1.80 ต่อนาที และ extra-switches 1.6 ซึ่งต่ำกว่าของ C1 แต่ยังสูงกว่า C2 ค่า mean absolute command change เท่ากับ 0.0046 แสดงว่าคำสั่งมีความเรียบและต่อเนื่อง ซึ่งสอดคล้องกับหลักการของ proportional control ที่ตอบสนองต่อ error แบบต่อเนื่อง และยังถูกจำกัดตาม command limits

### C0: baseline แบบ open-loop
C0 เป็น controller ที่ไม่ใช้ข้อมูลจากเซ็นเซอร์ จึงตามลำดับเวลาแบบคงที่แทนการตอบสนองตามระยะจริง ค่า latency ใกล้ศูนย์เมื่อเทียบกับการกำหนดช่วงเวลาที่ตั้งไว้ แต่ C0 ไม่สามารถปรับตัวให้เข้ากับความไม่แน่นอนของ environment ได้ ดังนั้น C0 จึงเป็น baseline ที่ใช้เป็นอ้างอิงมากกว่าเป็นตัวควบคุมที่มีความทนทาน

## 6. สรุป
ผลการทดลองแสดงให้เห็นถึงการแลกเปลี่ยนระหว่างความเร็วและความเสถียรอย่างชัดเจน C1 ตอบสนองเร็วที่สุดแต่ไวต่อ noise มากที่สุด ในขณะที่ C2 ตอบสนองช้ากว่าแต่มีความเสถียรและลดการสลับสถานะได้อย่างมาก C3 ให้สมดุลระหว่างทั้งสอง โดยมีการตอบสนองที่ต่อเนื่องและเรียบกว่า C1 แต่ไม่ใช่ตัวเลือกที่เสถียรเท่ากับ C2 จึงสรุปได้ว่าหากต้องการความทนทานต่อ noise C2 เป็นตัวเลือกที่เหมาะสมที่สุด ขณะที่ C1 เหมาะกับสถานการณ์ที่ต้องการความเร็วสูงและยอมรับความไม่เสถียรที่มากขึ้น
